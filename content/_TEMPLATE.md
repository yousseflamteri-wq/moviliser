HOW IT WORKS
• Everything above the second --- line is settings. Everything below is the prompt.
• teaser  = how many characters show for free on the card. The rest stays on the
            server and is never sent to the browser until someone unlocks. Default 70.
• image   = OPTIONAL. Put your own picture in  public/images/  and name it here
            (e.g. my-photo.jpg). This is the sample the card shows.
            If you leave `image` out, a sample is generated for you at build time.
• tags    = comma-separated. They become the category filter chips.

TO ADD A PROMPT: copy this file, rename it (e.g. sunset-portrait.md), fill it in,
put your image in public/images/, then push. That's it — one file per prompt.

Files starting with _ are ignored, so this template never appears on the site.
